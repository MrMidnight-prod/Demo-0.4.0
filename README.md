# rmcl — лаунчер Minecraft Java (Python + tkinter)

Тёмный интерфейс с боковой навигацией: **Играть · Моды · Железо · Журнал**. Только стандартная библиотека Python, без OpenGL.

## Возможности
- **Автоподбор под железо:** определяет CPU/ядра/RAM/видеокарту, выбирает профиль (слабый / средний / мощный),
  память игры, потоки GC, настройки графики (`options.txt`) и пресет модов. Всё можно переопределить вручную.
- **Загрузчики:** Vanilla, Fabric, Quilt, Forge, NeoForge (Forge/NeoForge ставятся официальным установщиком).
- **Моды:** поиск на Modrinth, своя сборка модов для каждого загрузчика, автоматические обязательные зависимости,
  удаление ранее установленных модов, которых нет в списке (ваши файлы не трогаются), импорт сборок `.mrpack`.
- **Живой поиск Modrinth:** результаты обновляются прямо во время набора (с задержкой 0,35 с, устаревшие ответы
  отбрасываются); пустой запрос показывает самые популярные моды; описание, автор и число загрузок, пометка ✓ у уже
  добавленных, двойной щелчок добавляет мод, кнопка «Показать ещё» подгружает следующую страницу.
- **Свои скины:** PNG-файл 64×64 (или HD 128×128 и т. д.) или публичный скин любого игрока по нику (Mojang API),
  предпросмотр спереди. Скин накладывается пакетом ресурсов на скин по умолчанию (`resourcepacks/rmcl-skin.zip`,
  включается в `options.txt`), поэтому работает в любой версии и с любым загрузчиком, без модов.
  В офлайн-режиме скин видите только вы. Старый формат 64×32 не поддерживается.
- Вход на сервер, автоскачивание Java (Windows x64), офлайн-ник.

## Установщик .exe через GitHub
1. Загрузите содержимое папки в репозиторий (включая `.github`).
2. **Actions → build-windows → Run workflow**.
3. Скачайте артефакт **rmcl-setup** (установщик) или **rmcl-portable** (папка без установки).

Данные: `%APPDATA%\rmcl`. Ошибки: `%APPDATA%\rmcl\error.log`.

## Тесты
`python tests_core.py`, `python tests_features.py`, `python tests_update.py`, `python tests_gui_smoke.py` (выполняются и в GitHub Actions).

## Ограничения
Только офлайн-ник (без входа Microsoft). CurseForge не подключён (нужен ключ API). Установщик не подписан.
